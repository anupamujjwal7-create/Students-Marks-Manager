# Student Text Manager

A simple command-line Python application for managing student records and checking pass/fail results.

## Features

* Add Student: Store a student's name and their corresponding marks.
* View Students: Display all stored students along with their marks.
* Check Result: Verify whether a specific student passed or failed based on a threshold of 30 marks.
* Exit: Safely terminate the program[cite: 1].

## Requirements

* Python 3.x

## How to Run

1. Open your terminal or command prompt.
2. Run the script using Python:

```bash
python student_text_manager.py
